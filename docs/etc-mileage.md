# ETCマイレージのポイント使用分と還元の残高

ETC利用照会の口座（種類は「その他」）の詳細画面に、ETCマイレージのポイントで払った分と還元の残高（円分）を出す。

## なぜ差額で出せるか

- ETC利用照会の口座の出金は、区間ごとの利用実績で、**ポイントを使う前**の通行料金
- カードからこの口座への振替は、**ポイントを使った後**の請求額
- ポイントで払った分だけ振替が少なくなり、口座に出金の残りが積もる。**出金の合計 − 振替の合計 ＝ ポイントで払った分（円分）**
- カード特典の集計（`docs/ledger-card-reward.md`）は振替を数えるので、すでにポイント使用後の額。ここでは直さない

## 数え方（`lib/etc-mileage.ts`）

- 数える取引: 確定した（`CONFIRMED`）支出（その口座が払った分）と、その口座への振替
- **差額は最新の振替の日付まで**で数える（`cutoff`）。振替は請求の確定まで遅れて届く（`docs/ledger-late-arrivals.md`）ので、
  それより後の出金は「請求待ち」として別に出し、使用分には入れない
- 還元の残高はETCマイレージサービスにしか無い。見た値を日付つきで手入力する（`LedgerMileageSnapshot`、`@@unique([accountId, date])`）。
  推定残高 ＝ 直近の入力値 − その日より後に使った分。**その後に増えた還元（5,000円分ずつなどまとめて行われる）は入っていない**ので、次の入力で直す
- 遅れて届いた振替が後から入ると、使用分は減る（請求待ちだった分が請求済みになるため）

## 持ち方と画面

- `LedgerAccount.mileageEnabled`。種類が「その他」の口座だけが true にできる（`parseAccountInput`）。口座の編集の「ETCマイレージ」で切り替える
- 画面は `components/ledger/mileage-progress.tsx`（口座の詳細画面。`account-history-content.tsx`）。「還元の残高を入力」で入力・削除する
- ETCマイレージサービスへのログインによる自動取得はしていない
