# 家計簿の収入の相殺（Issue #1343）

現金収入を先に「収入」で記録したあと、実際は現金を受け取らず別の口座（カード・銀行など）で支払い済みだったと
分かったときに、その収入を振替へ置き換える。

- 入口: 収入の編集ダイアログの「他の手段で相殺（振替にする）」。相殺先の口座を選んで実行する
- 結果: 同じ取引が `TRANSFER`（振替元＝元の入金先、振替先＝相殺先）に変わる。収入は収支・カテゴリ別から外れる
- 実装: `lib/ledger-offset.ts` の `buildOffsetTransfer` が更新の入力を作り、`updateEntryAction` を**1回**呼ぶ。
  新規作成＋削除に分けると片方だけ成功する経路ができるため、分けない
- メモには「収入から相殺（元の収入: N円）」を足す。専用の紐付けカラムは持たない（スキーマ変更なし）
- 元に戻すときは、通常の編集で種別を収入へ戻す
