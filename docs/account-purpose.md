# 口座の用途（Issue #965）

家計簿の口座（`LedgerAccount`）に `purpose`（投資／貯蓄／生活資金／生活防衛費／負債）を持たせ、
ホームの資産の内訳と、投資資産の画面に出すかどうかを決める。実装は `lib/account-purpose.ts`。

## 有効な用途の決め方（資産カテゴリ単位）

1. カテゴリの `excludeFromInvestmentView` が立っていれば、口座の用途が投資でも**生活防衛費**（負債は負債のまま）
2. カテゴリを結び付けた口座（`Category.ledgerAccountId`。#970）の用途
3. どちらも無ければ従来のフラグ（`isLiability`→負債、`isCash`→貯蓄、それ以外→投資）

- `hidden` の口座・用途が未設定の口座は使わない
- 子カテゴリに結び付けた口座の用途は親へ伝播し、子は親の用途に従う（集計はトップレベルだけを見る）。
  親自身の結び付けがあれば親が優先し、子どうしで口座が分かれるときは口座の `order`→`id` の先頭
- 結び付けの持ち方は `docs/ledger-account-holdings.md`

## 中身の資産カテゴリが無い口座（#1015）

カードのように結び付けるカテゴリが無い口座は、**家計簿で計算した残高をそのまま口座の用途の帯へ足す**
（`unlinkedAccountBreakdownItems`。ホームの `DashboardContent` で資産カテゴリと合わせて `computeAssetBreakdown` へ渡す）。

- 対象は「表示中・用途を設定済み・中身のカテゴリが0件」の口座だけ。用途が未設定の口座は数えない（#972 以前の表示を変えない）
- カードの残高はマイナスなので、用途「負債」なら負債の帯（純資産から差し引く）、「生活資金」なら生活資金から差し引く形になる
- 同じお金を結び付けていない資産カテゴリでも持っていると二重に数える。口座設定の説明で中身に選ぶよう案内している
- **用途が投資の口座は数えない**（#1030）。投資として数えるのは投資資産と連携した（中身を結び付けた）口座だけで、
  評価額は資産カテゴリの側で数える。家計簿の残高は振替の積み上げで、評価額ではないため
- 同じ理由で、口座の編集では中身を1つも選んでいないと用途「投資」を保存できない（`investmentPurposeError`。画面と
  `createAccount`・`updateAccount` の両方で見る）。制限より前から用途が投資の口座は、用途を変えるまでそのまま保存できる
- 効くのはホームの全体像の金額だけ。推移グラフ・前日比（資産カテゴリの履歴）と投資資産の画面（カテゴリ単位）には入らない

## 表示

- ホーム: 投資／貯蓄／生活資金／生活防衛費の帯と、別帯の負債（`computeAssetBreakdown`）
- 投資資産の画面: 投資用途のカテゴリだけ。履歴は `getFinancialSnapshot` の `investmentHistoryPoints`
  （投資用途のカテゴリだけで計算）を使い、サマリー・グラフ・構成一覧の母集団を揃える。
  「投資以外を含める」トグルは廃止した
- 口座の用途を変えると `revalidateUserDashboard` で集計のキャッシュ（300秒）を捨てる
